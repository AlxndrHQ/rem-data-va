# rem-data-va

Storage-only data for the Real Estate Map (https://alxndrhq.github.io/pg-county-land-map/): parcel tiles and detail files for DC AR AL FX PW LO FQ. Built by scripts in AlxndrHQ/pg-county-land-map and republished as a single commit.

Individually owned homes carry no owner name, mailing address or deed reference.
